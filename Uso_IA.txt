3. Explicacion de diferencia entre el nombre de la cola y el descriptor que permite acceder a ella.

    {{
        La diferencia es que representan dos cosas distintas: **el nombre de la cola y el descriptor que permite acceder a ella**.

        En tu código tienes:

        ```
        #define COLA "/mensajes"
        ```

        Y también:

        ```
        mqd_t cola_mostrador_deposito =
            mq_open(COLA, O_RDWR | O_CREAT, 0666, &attr);
        ```

        ### **1.&#x20;**`COLA`**: el nombre de la cola**

        `COLA` es una constante que contiene el nombre con el que identificas la cola en el sistema operativo.

        En este caso:

        ```
        #define COLA "/mensajes"
        ```

        Es como el nombre de un archivo: permite localizar el recurso.

        Por ejemplo, lo utilizas para abrir o eliminar la cola:

        ```
        mq_open(COLA, ...);

        mq_unlink(COLA);
        ```

        ### **2.&#x20;**`cola_mostrador_deposito`**: el descriptor**

        Esta variable es de tipo `mqd_t`:

        ```
        mqd_t cola_mostrador_deposito;
        ```

        Al ejecutar `mq_open()`, el sistema operativo devuelve un descriptor que guardas en esa variable.

        Es decir, representa el acceso que tiene tu proceso a la cola.

        Lo utilizas para enviar, recibir y cerrar mensajes:

        ```
        mq_send(cola_mostrador_deposito, ...);

        mq_receive(cola_mostrador_deposito, ...);

        mq_close(cola_mostrador_deposito);
        ```

        ### **3. Diferencia visual**

        **COLA**

        `"/mensajes"`

        Nombre que identifica la cola en el sistema

        **mq_open()**

        Abre la cola y devuelve un descriptor

        **cola_mostrador_deposito**

        `mqd_t`

        Descriptor utilizado para operar con la cola

        **Quédate con esta analogía:**

        - `COLA` es la dirección de una casa.
        - `cola_mostrador_deposito` es la llave que te permite acceder a ella.

        Y una última cuestión importante para tu práctica: al hacer `fork()`, los dos procesos hijos heredan el descriptor de la cola que abrió el padre. Por eso ambos pueden utilizar `cola_mostrador_deposito` sin tener que volver a ejecutar `mq_open()`.

    }}
